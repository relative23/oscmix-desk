# History

What the roadmap and the changelog said as work was planned and closed.
Historical text is preserved, including drafts that were later superseded;
archive notices identify their scope. The [current roadmap](../ROADMAP.md)
states what remains open, and accepted decisions live in
[docs/decisions/](../decisions/).

The archived TotalMix comparison is an old product-positioning draft,
not a current feature assessment. Its categorical claims about absent
saved state, startup recall, file versioning and scripting are not valid:
TotalMix has settings/workspace files, loading options and remote-control
interfaces. The [RME UCX II manual](https://rme-audio.de/downloads/fface_ucx2_e.pdf)
describes them in sections 25.6 and 28. The current project's distinction
is its declarative Linux lifecycle, not exclusive ownership of those
capabilities.
